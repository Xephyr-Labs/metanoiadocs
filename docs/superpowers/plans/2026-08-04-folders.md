# Folders and subfolders Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add first-class folders and nested subfolders, migrate existing parent-page trees, and organize the sidebar like AFFiNE.

**Architecture:** Add a folder table and `docs.folder_id`, expose folder CRUD/reorder routes, and render a separate folder tree in the existing sidebar. Keep document content and existing access semantics unchanged; folder deletion moves descendants upward instead of deleting them.

**Tech Stack:** Node.js, PostgreSQL, Express, React/TypeScript, Tailwind CSS, Node test runner, Vitest.
